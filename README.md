
# 🚀 API JS - Consumo de APIs con JavaScript

Proyecto desarrollado para practicar el consumo de APIs REST utilizando **HTML, CSS y JavaScript**, implementando peticiones HTTP con `fetch()` y renderizando información dinámica obtenida desde servicios externos.

## 📂 Repositorio

```bash
git clone https://github.com/CarlosPinto29/apiJs.git
cd apiJs
```

**GitHub:** https://github.com/CarlosPinto29

* HTML5

## 🎯 Objetivo

El objetivo de este proyecto es practicar:

* Consumo de APIs públicas.
* Manejo de promesas con JavaScript.
* Manipulación dinámica del DOM.
* Gestión básica de errores en peticiones HTTP.
* Separación de responsabilidades entre HTML, CSS y JavaScript.

## 🌐 APIs utilizadas

### Rick and Morty API

Obtiene información de personajes:

* Nombre
* Estado
* Imagen

https://rickandmortyapi.com

### JSONPlaceholder

Obtiene información de usuarios:

* Nombre
* Correo electrónico
* Teléfono

https://jsonplaceholder.typicode.com

Genera citas y frases aleatorias junto con su autor.

## ▶️ Ejecución rápida

### Con Live Server

1. Abrir el proyecto en Visual Studio Code.
2. Instalar la extensión **Live Server**.
3. Abrir `index.html`.
4. Presionar **Go Live**.

### Con Node.js

```bash
npx http-server -p 5500
```

Abrir:

```text
http://127.0.0.1:5500
```

### Con Python

```bash
python -m http.server 5500
```

Abrir:

```text
http://127.0.0.1:5500
```
